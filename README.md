# Conservativity of System $F_{<:}^\omega$

A Rocq formalization showing that the simply kinded, **beta-conversion**
variant of full $F_{<:}^{\omega}$ is conservative over full $F_{<:}$ for
subtyping and explicitly annotated typing judgments.

Both main proofs are complete for the calculi defined in this repository. They contain no admitted lemmas and have passed independent checking with `rocq check`. Their sole axiomatic dependency is dependent **functional extensionality**, inherited from the reused binding infrastructure.

## Main Results

Let $\mathcal B$ denote full $F_{<:}$ and $\mathcal H$ its simply kinded
higher-order extension with beta conversion. An *old* type or term belongs
to the syntax of $\mathcal B$. When viewed in $\mathcal H$, its type
variables have kind $*$.

**Subtyping conservativity.** For a well-formed old type-variable context
$\Gamma$ and old types $S,T$ well formed in that context,

$$
\Gamma\vdash_{\mathcal H} S<:T::*
\quad\Longleftrightarrow\quad
\Gamma\vdash_{\mathcal B} S<:T.
$$

Adding type operators therefore creates no new subtyping judgments between
old types in old contexts. [Formal proof](theories/Conservativity.v).

**Typing conservativity.** For well-formed old contexts $\Gamma,\Delta$,
an explicitly annotated old term $t$, and an old result type $T$ well formed
under $\Gamma$,

$$
\Gamma;\Delta\vdash_{\mathcal H} t:T
\quad\Longleftrightarrow\quad
\Gamma;\Delta\vdash_{\mathcal B} t:T.
$$

Here $\Gamma$ records type-variable bounds and $\Delta$ records term-variable
types. The term's annotations and explicit type arguments also belong to
the old language. [Formal proof](theories/TypingConservativity.v).

The higher-order derivations may use arbitrary intermediate types,
including type operators and quantification over operators. Only the
contexts, terms, and endpoints in these statements must be old.

The proofs establish a stronger projection property: every well-kinded
higher-order proper type in an old context has a unique old normal-form
representative after erasure. This projection preserves subtyping and
typing of old terms, even when the original result types contain
higher-order syntax.

## Calculus

The higher-order system has:

- Simple kinds `Star` and `KArr K L`.
- Type-operator abstraction and application, with beta conversion.
- Unbounded operator parameters, represented by the maximal bound `top K`.
- Pointwise operator subtyping: `F <: F'` gives `F C <: F' C` for the same
  argument `C`.
- Full bounded universal subtyping, with a contravariant bound.

Both systems retain declarative transitivity. The full universal rule is
essential: its two bounds may differ.

The current formalization covers beta conversion only. Eta conversion,
recursive types, dependent or interval kinds, and additional variance
rules are outside its scope. It does not yet connect the conservativity
proof to a mechanized undecidability reduction, and makes no claim that
the mathematical result is new to the literature.

The complete syntax and inference rules are typeset with LaTeX's
`mathpartir` package. Download the [three-page rule sheet](assets/rules.pdf)
or read its [LaTeX source](assets/rules.tex).

## Build and Check

The validated environment is:

| Dependency                           | Version                                                      |
| ------------------------------------ | ------------------------------------------------------------ |
| OCaml                                | 5.4.1                                                        |
| Rocq                                 | 9.2.0                                                        |
| Rocq Stdlib                          | 9.1.0                                                        |
| Dune                                 | 3.22.2                                                       |
| Coq Library of Undecidability Proofs | `dev+9.2`, commit `c7257b736763d7b2bc3bd25ac47d5fb7ce749c9c` |

With the existing `ocaml-5.4.1-rocq-9.2` opam switch:

```sh
make          # Compile all proofs and examples
make check    # Compile, audit assumptions, and independently check proof terms
```

To use another compatible switch, install the dependencies declared in
[rocq-fsubomega.opam](rocq-fsubomega.opam) and select it explicitly:

```sh
opam install --switch=my-switch . --deps-only
make OPAM_SWITCH=my-switch check
```

The manifest uses `pin-depends` to fix the Undecidability library commit.

`make check` performs three checks:

1. `dune build @all` compiles the development and examples.
2. `dune build @runtest` compares the main theorems' `Print Assumptions` output against [Assumptions.expected](tests/Assumptions.expected).
3. `rocq check` independently checks both main theorem modules, the example module, and their dependencies. No dependency-checking bypass is used.

`make clean` removes build artifacts.

  [Author's publication page](https://www.cis.upenn.edu/~bcpierce/papers/index.shtml#PierceSteffen95).
  Its kernel quantifier rule must be distinguished from the full rule used here.

  [Paper](https://arxiv.org/html/2107.01883).
  Their interval-kind calculus has a different scope.
- [Coq Library of Undecidability Proofs](https://github.com/uds-psl/coq-library-undecidability),
  including the HOU development and its Autosubst binding infrastructure.
